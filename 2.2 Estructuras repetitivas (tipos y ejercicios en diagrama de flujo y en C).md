## 🔸 Ciclo mientras (while)

> while es una estructura de programación que ejecuta un bloque de código repetidamente mientras se cumpla una condición.

### Sintaxis

```c
while (condición) {
    // código que se repite mientras la condición sea verdadera
}

```

### 💻 Ejemplo

Escribe un programa que pida al usuario números enteros y los sume.
El programa debe continuar pidiendo números hasta que el usuario ingrese 0, momento en el que se mostrará la suma total de los números ingresados.


### Código implementado en C

```c
#include <stdio.h>

int main() {
    int numero, suma = 0;

    printf("Ingresa un numero (0 para terminar): ");
    scanf("%d", &numero);

    while (numero != 0) {
        suma += numero;
        printf("Ingresa otro numero (0 para terminar): ");
        scanf("%d", &numero);
    }

    printf("La suma total es: %d\n", suma);

    return 0;
}
```

## 🔸 Ciclo hacer mientras (do-while)

> do-while es un bucle que ejecuta primero el bloque de código y luego verifica la condición, garantizando que se ejecute al menos una vez.

### Sintaxis

```c
do {
    // código a ejecutar
} while (condición);

```

### 💻 Ejemplo

Realiza un programa en C que permita al usuario ingresar números enteros de forma repetida.
El programa debe sumar todos los números ingresados y finalizar cuando el usuario introduzca el número 0.
Finalmente, debe mostrar la suma total de los números ingresados (excluyendo el 0).

### Código implementado en C

```c
#include <stdio.h>

int main() {
    int numero, suma = 0;

    do {
        printf("Ingresa un numero (0 para terminar): ");
        scanf("%d", &numero);
        suma += numero;
    } while (numero != 0);

    printf("La suma total es: %d\n", suma);

    return 0;
}
```

## 🔸 Ciclo para (for)

### Sintaxis

```c
for (inicialización; condición; incremento) {
    // código a ejecutar en cada iteración
}
```

### 💻 Ejemplo

Escribe un programa que calcule la suma de todos los números pares del 1 al 20
e imprima también cuántos números pares se sumaron.

### Código implementado en C


```c

#include <stdio.h>

int main() {
    int suma = 0;
    int contadorPares = 0;

    for (int i = 1; i <= 20; i++) {
        if (i % 2 == 0) {  // Verifica si el número es par
            suma += i;
            contadorPares++;
        }
    }

    printf("La suma de los números pares del 1 al 20 es: %d\n", suma);
    printf("Cantidad de números pares sumados: %d\n", contadorPares);

    return 0;
}
```

## 🔸 Anidamiento de estructuras repetitivas (bucles anidados)

> Bucles anidados significa usar un bucle `for` dentro de otro bucle `for`.  
> 
> - El bucle externo controla un ciclo principal.  
> - El bucle interno se ejecuta completamente cada vez que se ejecuta una iteración del bucle externo.  
> - Se usa cuando necesitamos recorrer estructuras de dos dimensiones o hacer operaciones repetitivas dentro de otra repetición, como tablas, matrices o patrones.


## 🔸 Ejercicio combinando estructura condicional y repetitiva (Java)

### 💻 Enunciado

Escribe un programa en Java que pida al usuario ingresar una contraseña.  
El usuario tendrá 3 intentos para escribir la contraseña correcta:  

- Si la contraseña es correcta, el programa debe mostrar un mensaje de **“Acceso concedido”**.  
- Si la contraseña es incorrecta, debe mostrar **“Contraseña incorrecta”**.  
- Si el usuario falla los 3 intentos, el programa debe mostrar **“Acceso bloqueado”**.

**Análisis:**

- **Datos de entrada:** Contraseña ingresada por el usuario.  
- **Proceso:** Condición que deja o impide ingresar al sistema dependiendo de si se ingresó correctamente la contraseña.  
- **Datos de salida:** Mensajes: “Acceso concedido” y “Acceso bloqueado”.  
- **Diseño:** Se realiza en pseudocódigo y diagrama de flujo antes de codificar.  
- **Codificación:** Se traslada el pseudocódigo a código fuente en Java.  
- **Ejecución:** Se comprueba que el programa funcione correctamente.

### Código implementado en Java

```java
import java.util.Scanner;

public class Login {
    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);
        final String PASSWORD_CORRECTA = "1234";
        String passwordIngresada;
        int intentos = 3;

        while (intentos > 0) {
            System.out.print("Ingresa la contraseña: ");
            passwordIngresada = sc.nextLine();

            if (passwordIngresada.equals(PASSWORD_CORRECTA)) {
                System.out.println("Acceso concedido");
                break; // termina el bucle
            } else {
                intentos--;
                System.out.println("Contraseña incorrecta. Intentos restantes: " + intentos);
            }
        }

        if (intentos == 0) {
            System.out.println("Acceso bloqueado");
        }

        sc.close(); // cerrar el Scanner
    }
}
```
