# Modularidad en Programación

## 📌 ¿Qué es la modularidad?

La **modularidad** es un principio fundamental de la programación que consiste en dividir un programa en partes más pequeñas llamadas **módulos** o **funciones**.  
Cada módulo se encarga de una tarea específica, lo que permite organizar mejor el código y facilitar su comprensión.

### ✅ Ventajas de la modularidad
- Mejora la **legibilidad** del código  
- Facilita el **mantenimiento** y la corrección de errores  
- Permite la **reutilización** de código  
- Hace el desarrollo más **ordenado y eficiente**

## 🔹 Función

Una **función** es un bloque de código independiente que realiza una tarea específica y puede ser reutilizado en diferentes partes del programa.  

#### Estructura básica de una función:
- **Tipo:** Define el tipo de dato que devuelve la función (por ejemplo, `int`, `float`, `void`).  
- **Identificador:** El nombre de la función, usado para llamarla.  
- **Parámetros:** Datos que recibe la función para procesar (opcionales).  
- **Instrucciones:** Conjunto de sentencias que ejecuta la función.  
- **Valor de retorno:** Lo que devuelve la función (si no es `void`).


---

## 📌 Pase de parámetros

Cuando una función recibe datos desde el programa principal, estos se pasan mediante **parámetros**. Existen dos formas principales:

---

## 🔹 Pase de parámetro por valor

En el **pase por valor**, la función recibe una **copia del valor** de la variable original.  
Los cambios realizados dentro de la función **no afectan** a la variable original.


# 📘 Ejercicio 1: Pase de Parámetros por Valor

## 📌 Planteamiento

Desarrollar un programa en lenguaje **C**,que permita calcular el **área de un rectángulo** aplicando el **pase de parámetros por valor**.

El programa deberá contar con una función que reciba la base y la altura como parámetros, calcule el área y retorne el resultado, sin modificar las variables originales.

---

## 💻 Código en C (Paso por Valor)


```c
#include <stdio.h>


float calcularArea(float base, float altura) {
    float area;
    area = base * altura;
    return area;
}

int main() {
    float base, altura, area;

    printf("Ingrese la base del rectangulo: ");
    scanf("%f", &base);

    printf("Ingrese la altura del rectangulo: ");
    scanf("%f", &altura);

    area = calcularArea(base, altura);

    printf("\nEl area del rectangulo es: %.2f\n", area);

    return 0;
}

```

## 🔁 Pase por Referencia

📌 En el **pase por referencia**, la función recibe la **dirección de memoria** de la variable original.

✅ Los cambios realizados dentro de la función **sí afectan directamente** a la variable original.


# 📘 Ejercicio 2: Pase de Parámetros por Referencia

## 📌 Planteamiento

Se desea desarrollar un programa en lenguaje **C**, que permita **incrementar la edad de una persona**.

El programa contará con una **función** que reciba la **dirección de memoria** de la variable `edad` y le sume un número de años ingresado por el usuario.


---
