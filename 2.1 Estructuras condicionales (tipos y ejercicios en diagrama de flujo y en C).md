<h3 align="center"> # 📘 Estructuras condicionales (tipos y ejercicios en diagrama de flujo y en C)

🔍 **Las condicionales** son estructuras de programación que permiten tomar **decisiones**:  
ejecutan un bloque de código solo si se cumple una condición.

En otras palabras, permiten que un programa **elija entre diferentes acciones** según lo que esté ocurriendo.

## 🔸 Estructuras Condicionales simples

<span style="color:#9b59b6;"><strong>Si (if)</strong></span>

Ejecuta un código si la condición es verdadera y otro distinto si es falsa.

```c
if (condición) {
    // si es verdadera
} else {
    // si es falsa
}
