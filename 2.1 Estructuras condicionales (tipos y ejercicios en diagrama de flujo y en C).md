<h3 align="center">📘 Estructuras condicionales (tipos y ejercicios en diagrama de flujo y en C)</h3>

> 🔍 **Las condicionales** son estructuras de programación que permiten tomar **decisiones**: ejecutan un bloque de código solo si se cumple una condición.  
>
> En otras palabras, permiten que un programa **elija entre diferentes acciones** según lo que esté ocurriendo.

## 🔸 Estructuras Condicionales simples

<span style="color:#9b59b6;"><strong>Si (if)</strong></span>

Ejecuta un código si la condición es verdadera y otro distinto si es falsa.

### Sintaxis 

```c
if (condición) {
    // si es verdadera
} else {
    // si es falsa
}

```


 ### 💻 Ejemplo

Realiza un programa en lenguaje C que pida al usuario un número entero y muestre un mensaje indicando que el número es positivo solo si es mayor que cero. Si no lo es, el programa simplemente termina sin mostrar ningún mensaje adicional.


### Código implementado en C.

```c
#include <stdio.h>

int main() {
    int numero;

    printf("Ingresa un número entero: ");
    scanf("%d", &numero);

    // Estructura condicional simple
    if (numero > 0) {
        printf("El número es positivo.\n");
    }

    return 0;
}

```

## 🔸 Estructuras condicionales dobles si-si no (if-else)

> Ejecuta un código si la condición es verdadera y otro distinto si es falsa.

### Sintaxis

```c
if (condición) {
    // si es verdadera
} else {
    // si es falsa
}

```

### 💻 Ejemplo

Realiza un programa que pida al usuario un número entero y determine si es positivo o negativo.
Si el número es mayor que cero, mostrar el mensaje: "Es positivo".
En caso contrario, mostrar: "Es negativo o cero".


### Código implementado en C

```c

#include <stdio.h>

int main() {
    int numero;

    printf("Ingresa un número entero: ");
    scanf("%d", &numero);

    if (numero > 0) {
        printf("Es positivo.\n");
    } else {
        printf("Es negativo o cero.\n");
    }

    return 0;
}


```

## 🔸 Estructuras condicionales múltiples (switch)

> Se usa para comparar una variable contra múltiples valores fijos de manera más ordenada que varios else if.

### Sintaxis

```c
switch (variable) {
    case valor1:
        // acción 1
        break;
    case valor2:
        // acción 2
        break;
    default:
        // acción por defecto
}

```

### 💻 Ejemplo

Realiza un programa que pida al usuario un número entero y determine si el número es positivo, negativo o cero.


### Código implementado en C

```c
#include <stdio.h>

int main() {
    int numero;

    printf("Ingresa un numero entero: ");
    scanf("%d", &numero);

    switch ((numero > 0) ? 1 : (numero < 0 ? 2 : 0)) {
        case 1:
            printf("El numero es positivo.\n");
            break;
        case 2:
            printf("El numero es negativo.\n");
            break;
        case 0:
            printf("El numero es cero.\n");
            break;
        default:
            printf("Error.\n");
    }

    return 0;
}

```

## 🔸 Anidamiento de estructuras condicionales

> Una condición anidada ocurre cuando dentro de un bloque condicional (Si…Sino, if…else) se coloca otra condición. Esto permite tomar decisiones más complejas dependiendo de múltiples criterios.

### 💻 Ejemplo

Realiza un programa en C que pida al usuario su edad y si tiene licencia de conducir:  

- Si la persona tiene 18 años o más, se pregunta si tiene licencia:  
  - Si tiene licencia → mostrar “Puede conducir legalmente”.  
  - Si no tiene licencia → mostrar “No puede conducir legalmente”.  
- Si la persona es menor de 18 años → mostrar “No puede conducir legalmente”.

### Código implementado en C

```c
#include <stdio.h>

int main() {
    int edad;
    char licencia;

    printf("Ingresa tu edad: ");
    scanf("%d", &edad);

    if (edad >= 18) {
        printf("Tienes licencia de conducir? (S/N): ");
        scanf(" %c", &licencia); // el espacio antes de %c es importante

        if (licencia == 'S' || licencia == 's') {
            printf("Puede conducir legalmente.\n");
        } else {
            printf("No puede conducir legalmente.\n");
        }
    } else {
        printf("No puede conducir legalmente.\n");
    }

    return 0;
}
```
